# Manufacturing-Quality-Analyzer-Clt-Hypothesis-Testing
Manufacturing Quality Analyzer using CLT and Hypothesis Testing to monitor production quality, detect process deviations, and support data-driven quality control decisions.
Manufacturing Quality Analyzer
This project applies statistical quality control techniques to manufacturing data using the Central Limit Theorem (CLT) and Hypothesis Testing. It helps analyze production performance, validate process consistency, and detect quality issues through data-driven statistical methods.
Features


Sample mean and distribution analysis using CLT


One-sample and two-sample hypothesis testing


Defect rate analysis


Confidence interval estimation


Statistical quality monitoring dashboards


Data visualization for production insights


Technologies Used


Python


Pandas


NumPy


SciPy


Matplotlib / Seaborn


Jupyter Notebook


Use Cases


Production quality monitoring


Process stability analysis


Manufacturing defect detection


Statistical decision-making in quality assurance


One-Line Tagline
Statistical quality control for manufacturing using CLT, confidence intervals, and hypothesis testing.
